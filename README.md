# Cafeteria America Website

A modern and responsive restaurant website designed to provide customers with an easy way to explore the menu, place orders, and reserve a table.

## Features

- Responsive design for desktop and mobile
- Interactive food menu
- Shopping cart with quantity controls
- WhatsApp ordering
- Table reservation form
- Floating cart button
- Clean and modern user interface

## Built With

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Vite
